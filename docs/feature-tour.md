## 附录：命令行与离线迁移

下面是用法参考，**不表示本轮重新执行了真实数据迁移**。实际迁移要求、归档边界与恢复步骤见 [使用指南](../README.md#升级到-030) 和 [架构说明](architecture.md#offline-cutover--离线切换)。

```powershell
# 启动菜单；launch.vbs 也可使用 Harness 自带的 Python
python launcher.py

# 指定独立的启动器记录目录，不自动打开窗口
python launcher.py --data D:\demo\launcher-data --no-open

# 离线迁移：先预检，确认后才应用
python migrate.py --data D:\demo\launcher-data
python migrate.py --data D:\demo\launcher-data --apply

# 仅在目录切换中断时恢复
python migrate.py --data D:\demo\launcher-data --recover
```

`DSH_HOME` 指定 Harness 数据目录，`DSH_EXECUTABLE` 指定应用路径；环境变量提供首次初始化的默认值，已有保存设置优先。更多选项见 [命令行参数与环境变量](../README.md#命令行参数与环境变量)。`--data` 控制启动器自己的设置、备份和快照目录，不等于 Harness 的数据目录。
