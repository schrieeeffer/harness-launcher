# Harness Launcher

为 DeepSeek Harness 提供启动组合、官方与社区插件发现，以及可复核的文件补丁记录。使用本机浏览器与 Python 标准库，无第三方运行依赖。

本项目由社区独立维护，与 DeepSeek 官方没有隶属关系。当前版本为开发预览，**Windows 桌面版已验证；macOS/Linux 尚未完成安装路径、进程检测与补丁适配，请勿将其视为跨平台认证版本。**

## 能做什么

- 发现插件：官方常用组合包、npm 社区搜索、GitHub `dsh-plugin` topic 仓库搜索，支持来源筛选、分页、失败重试和短期缓存。
- 查看详情：包名、版本、来源、许可证、源代码链接、声明的 Harness 依赖，检查是否存在 `dsh.bundle.patch`。普通组件库不能从目录直接安装。
- 保留自由添加：npm 包及版本、本地目录、Git/HTTPS 来源；搜索选用只是预填表单，不会立即安装。
- 选择启动组合：逐项开关、全选、全部关闭、保存方案与导入/导出。
- 修改前备份配置；已记录插件关闭时还原文件、启用时重新应用；冲突或版本变化时停止覆盖。
- 安装与升级记录：安装前快照 → 安装和首次测试 → 退出 Harness → 扫描并复核归属。升级先撤销旧层，新记录确认后替换，历史记录保留。

## 快速开始（Windows）

需要已经初始化 desktop profile 的 DeepSeek Harness，以及 **Python 3.12+**。

1. 下载源码或克隆此仓库，放在 Harness 安装目录以外。
2. 使用 Python 启动：

   ```powershell
   python launcher.py
   ```

   如果使用 Harness 自带 Python，请替换为安装目录内 `resources\runtime\primary-runtime\dependencies\python\python.exe` 的实际路径。
3. 打开「设置与说明」，确认 `DeepSeek Harness.exe` 与数据目录（默认 `%USERPROFILE%\.dsh`）。首次找不到配置时，该设置入口仍可使用。
4. 完全退出 Harness（包括托盘），选择插件并点击「应用选择」或「启动 Harness」。不会强制关闭正在运行的会话。

可选：设定环境变量 `DSH_EXECUTABLE` 指向应用，`DSH_HOME` 指向 Harness 数据目录。保存设置后可双击 `launch.vbs` 隐藏控制台启动；它优先使用 Harness 自带 pythonw，其次使用 PATH 中的 pythonw。也可为 `launch.vbs` 创建桌面快捷方式。

浏览器和管理器仅通过本机 `127.0.0.1` 通信。优先使用 Edge 应用窗口，否则打开默认浏览器；重复启动复用服务。所有菜单关闭且无快照/安装工作时，空闲约 5 分钟后服务退出。

## 发现和安装插件

在「发现插件」搜索，按“官方 / 社区 npm / GitHub”筛选，再打开详情。

- 官方默认列出四个常用实验性组合包；输入包名可查询其他官方组件。随 Harness 提供的官方功能建议优先在官方插件页启用，避免重复安装。
- npm 搜索依赖作者的生态关键词，GitHub 搜索依赖 `dsh-plugin` topic；未标记的项目可能需要完整包名或手动添加。目录不是完整市场，也没有人工安全审核。
- npm 详情锁定查询到的版本；GitHub 详情读取根目录 package.json，仓库没有根包时会提示查看说明并手动添加。仓库地址安装不锁定 commit，请按项目说明填写固定 ref。
- 中国大陆镜像选项仅影响目录查询；安装沿用 Harness 包管理器自己的 registry 配置。
- 网络部分失败时保留其他来源结果并报告失败。5 分钟缓存过期后若无法联网，可显示旧结果并标记，旧详情不能直接选用安装。

点击「选用并准备安装」后检查预填来源，再点击「建立快照并开始」。社区安装可能执行第三方代码；声明了组合包结构不等于安全或兼容性认证。

## 补丁还原的边界

内置 dsh-purge 适配器适用于已捕获且版本匹配的安装；它保存官方 ASAR，暂存解包应用和已识别的规则/预设。dsh-purge 升级需要重新校验，不会自动把旧快照应用到新版本。

通用记录只追踪明确范围内的文件变化，**不是进程级归属审计，也不是整机还原**。安装前必须开始记录；首次测试后需要复核。窗口内只安装、升级、测试一个插件。注册表、系统服务、驱动、外部路径不在范围内；后续运行产生的新补丁需要重新处理。已有未知插件无法凭空补回安装前状态。

应用文件、规则和预设快照保存在管理器数据目录的 `patches`，非激活文件可能在 `resources/.harness-launcher-*` 或用户数据目录的同名暂存目录中。**不要手动删除这些目录**。关闭插件保留已安装依赖、账号和会话；“全部关闭”遇到未知补丁会拒绝宣称完整原生状态。

详见 [完整记录与恢复说明](docs/patch-recording.md) 和 [安全与数据说明](SECURITY.md)。

## 开发与测试

```powershell
python -m unittest discover -v
node --check ui/app.js
```

测试使用临时 profile、合成 ASAR 和模拟远端响应，不会对真实安装做破坏性测试。Windows CI 覆盖 Python 3.12 / 3.13。网络服务状态、未来 Harness/插件版本和特定机器环境仍可能出现问题，欢迎提供可复现步骤。

管理器个人配置和日志默认保存在 `%LOCALAPPDATA%\HarnessLauncher`。命令行 `--data <目录>` 可隔离测试数据，`--no-open` 可只启动本机服务。
