## 下载与启动

1. 安装并打开一次官方 DeepSeek Harness 桌面版。
2. 从 Release 下载 `Harness-Launcher-0.4.1-Windows-x64.zip`，完整解压。
3. 双击 `Harness Launcher.exe`。便携包自带 Python，无需安装开发环境。
4. 若未找到 Harness，在“设置与说明”中自动检测或填写程序路径。

源码运行需要 Python 3.12+，可双击 `launch.vbs`，或运行 `python launcher.py`。有 Edge 时以独立应用窗口打开，否则使用默认浏览器。源码只使用 Python 标准库，不需要 pip 依赖。

主 EXE 尚未做商业代码签名；请从本仓库 Release 下载，校验文件为 `SHA256SUMS.txt`。便携包不包含官方 Harness、第三方插件或个人数据。

## 日常使用

| 功能 | 操作与效果 |
| --- | --- |
| 选择插件 | 开关编辑本次选择草稿；搜索名称或描述，使用全选、全部关闭、当前配置及原生模式快捷选择。 |
| 启动 Harness | 校验并应用选择，然后启动应用；进度条显示实际阶段、文件数量和已用时间，不预测剩余时间。 |
| 仅应用，不启动 | 只提交当前组合，方便预先配置；单独切换开关不会立即修改应用文件。 |
| 保存方案 | 将组合命名保存；方案记录版本约束，版本变化后需要检查并重新保存。支持 JSON 导入、导出与导入预览。 |
| 发现插件 | 浏览官方组合包、npm 社区包及 GitHub 插件，支持搜索、来源筛选、分页和下载量排行。 |
| 手动添加 | 支持 npm、本地目录和 Git 来源；安装前记录快照，安装及首次运行后核验变化。安装脚本可能执行第三方代码，请选择可信来源。 |
| 补丁记录 | 查看记录范围和恢复能力。普通插件按文件差异恢复，purge 使用专用适配器；未记录的改动不能保证撤销。 |
| 配置备份 | 改配置前自动备份；恢复前再次备份。配置备份有版本约束，不等同于整个系统或插件代码备份。 |
| 设置与说明 | 配置程序和数据路径、查看更新边界、退出启动器后台。运行中的 Harness 通常需要先退出，才能切换文件。 |
| 官方运行时修复 | 在设置中完整检查同版本官方安装包，预览并补齐缺失文件。验证签名、SHA-512 和宿主一致性；已有内容冲突时停止。需要安装 7-Zip。[操作说明与截图](docs/runtime-repair.md)。 |

## 更新、卸载与恢复

在“更新与卸载”中操作：

- **检查更新**：按插件来源查询版本；安装目标固定为 npm 精确版本或 Git 提交，保留本地及私有来源边界。
- **预览升级**：检查宿主及依赖，建立维护检查点，安装后完成首次运行验证。普通插件和 purge 分别处理；purge 声明的宿主目标不匹配时拒绝升级。
- **预览卸载**：先展示受影响文件和阻止原因。保留外部本地源目录；用户后续改动和共享依赖冲突会阻止操作。
- **恢复检查点**：先预览再恢复；检查点之后出现未知改动时停止，保留证据。
- **清理无引用缓存**：复核当前组合、方案、历史、备份及恢复点的引用，仅回收超过宽限期的无引用对象。不清理全局包管理器缓存、共享依赖或用户会话。

详见[插件维护范围](docs/plugin-maintenance.md)和[官方 Harness 更新说明](docs/host-updates.md)。官方更新前应先退出 Harness、还原原生，再使用官方更新入口。启动器不能拦截官方更新器；宿主身份变化后会停止重放不匹配的补丁。

## 校验、性能与数据

日常启动复用内容身份缓存和 NTFS 目录检查点，仍保留校验与事务回滚。首次检查、文件变化、下载或维护可能较慢；日常启动不自动查询远端更新或执行垃圾回收。

本机完整窗口复测为 **20.8–35.1 秒**，另有一次 **42.7 秒**慢样本，不保证每次或所有机器都在 30 秒内。公开截图使用隔离示例数据，不代表真实第三方升级验收，详见[完整验证记录](docs/validation-0.4.0.md)。

数据默认保存在 `%USERPROFILE%\.harness-launcher`，包括设置、校验缓存、补丁记录、备份与恢复材料。服务只监听 `127.0.0.1`，使用随机访问令牌。插件发现与更新检查需要网络。

请保留恢复数据，不要通过删除数据目录解决冲突。程序仅接受当前格式；格式不支持或数据损坏时停止操作。配置恢复、补丁恢复与维护检查点均继续提供。

## 退出与卸载启动器

从“设置与说明”退出后台，再删除启动器程序目录。需要保留插件恢复能力时，应保留启动器数据目录。移除启动器本身不会自动撤销第三方插件的改动；请先使用维护界面预览相应操作。
