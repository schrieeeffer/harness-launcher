    操作预览

      
    
      
        

  
    
      
      
      设置与说明
      确认 Harness 程序与数据目录，导入导出启动方案。
      
      
    
      
    
      
      
      
        
      路径
      
        
      
          
          
      
        
      
        
        
      自动检测会读取安装程序登记的位置，自定义安装目录也能找到。数据目录内应有 profiles\desktop\package.json；更换数据目录会清空当前方案列表，如需保留请先导出方案。
      
        
      
        
      
      
      

      
      
        
      方案与文件
      
        
      
          
          
          
          
        
      
        
      导出为 JSON 文件，可备份或分享给他人。导入前会先预览：同名方案将被覆盖，含本机未安装插件的方案会被跳过并列出缺少的插件。导入只更新方案列表，不修改 Harness。
      
      
      

      
      
        
      Harness 与插件更新
      
        
        
          
      • 官方更新：先退出 Harness，在启动器中切换到原生模式并启动，再使用官方更新。新版安装完成后，旧插件记录需要重新适配；启动器会保留记录并停止跨版本覆盖。
        • 
          
      • 启用插件时更新：启动器无法拦截 Harness 内的更新或更新器自动重启。若已更新，请保留现场，避免强制还原旧补丁；先确认新版的干净安装，再记录兼容插件。
        • 
          
      • 插件更新与卸载：在“更新与卸载”中统一检查版本，先看预览再执行。维护前保存可恢复检查点；升级后需要正常运行并退出，再完成验证。其他插件及共享依赖发生变化时会停止。
        • 
          
      • purge 更新：使用专用维护流程，先校验并还原旧补丁，安装指定版本后重新应用并验证。新版必须声明适配当前 Harness；跨宿主版本不能沿用旧补丁。
        • 
        
      
        
      检查或下载更新不会自动更换基线。校验失败时保留日志、快照和会话；清空缓存或修改版本号不能解决版本不兼容。
      
      
      

      
      
        
      官方运行时修复
      
        
      更新后提示 SKILL.md、Python 或其他运行时文件缺失时，先完全退出 Harness，再检查。默认读取官方更新缓存，也可指定同版本官方安装包。
      
        
        
        
      
        
      日常只检查必需文件，完整检查和修复可能需要数分钟。
      
        
      
        
      
        
      
        
      验证 DeepSeek 发布者签名、SHA-512、主程序及 app.asar 一致性。只补齐缺失文件；已有文件不同就停止，不覆盖插件改动。账号、会话、工作区及回滚记录不参与修复。需要已安装的 7-Zip。修复不会自动启动应用。
      
      
      
      
      
        
      官方更新后原生启动
      
        
      运行时修复后仍提示“宿主文件已变化”？使用上方安装包验证新版官方文件，再保存独立的原生启动基线。要求更新前已还原原生组合、当前未启用插件且没有未完成操作。
      
        
      不会改写旧补丁、安装文件或用户数据。旧插件仍受版本校验限制，本入口不自动迁移或重新记录旧插件。完整验证只在建立基线时解包；日常启动复用文件校验缓存。
      
        
      
        
      
      
      

      
      
        
      启动器后台
      
        
      关闭菜单窗口后，后台仍会运行并完成安装记录。再次打开菜单会复用后台，电脑休眠或网页暂停刷新不会让后台自动退出。
      
        
      
        
      退出后，所有已打开的启动菜单都会断开；下次使用请重新双击桌面快捷方式或 launch.vbs。正在安装、记录或切换时会阻止退出。已启动的 Harness 会继续运行。
      
      
      

      
      
        
      如何使用
      
        
        
          
      • 开关只调整待选组合。「启动 Harness」会自动应用变更后启动；组合未变时校验当前文件后直接启动。「仅应用，不启动 / 仅还原，不启动」用于提前同步配置与补丁。
        • 
          
      • 关闭插件不会卸载插件。安装新插件请使用「手动添加」或从「发现插件」选用，安装前会自动建立快照；各插件能否还原可在「补丁记录」查看。官方基础组件不能关闭，插件启动次序沿用配置中的顺序。
        • 
          
      • 切换前请完全退出 Harness，包括托盘。菜单会检查运行状态，不会强制关闭会话。
        • 
          
      • dsh-purge 支持自动还原：原生模式使用保留的官方归档，并暂存插件注入规则、提示词和红队预设；启用时恢复同版本补丁快照。其他插件可通过通用安装前后快照登记文件差异，无需逐个写适配器；没有安装前记录时仍会阻止宣称完整还原。账号、会话和普通偏好不重置。
        • 
          
      • 应用前自动备份 package.json，保留账号、会话、其他配置和已安装依赖。恢复配置备份也会同步已适配插件的补丁状态，不回退插件版本。切换有日志，失败自动回滚；版本升级或检测到外部文件改动时停止覆盖。
        •

          安装来源
          
          
          
          
        
        
        
        
        
        
        
        
      
        

      
        
        
        
        
        
        
        
        
        
        
        
          
        在 Harness 中正常使用即可
        
          
        
          
          
        
        
        
        
        
        
          
          
          
          
        
        
        
        可以关闭菜单窗口，后台会继续记录。退出 Harness 时请一并退出托盘程序；安装完成前只操作这个插件。
        
        
        
          取消尚未开始的安装
          
        只有插件尚未安装且文件没有改动时才能取消。有改动时会保留记录，避免失去还原依据。
        
          
        
        
      
        

      
        安装会运行插件代码。还原记录始终开启；记录完成前不能切换插件组合。历史与升级入口在。
        
    
        
          

  
    
        
      
        补丁记录
        记录插件安装前后的文件差异，关闭时据此还原、启用时恢复。没有安装前记录的插件不能保证还原。
        
      
    
        
    
        
      
        
        
        
        正常使用并退出 Harness 后自动校验保存；遇到异常时会保留原始快照。
        
        
      
        

      
        
        
        已记录 0
        
        
        关闭 / 启用时自动还原文件。升级时先撤销旧版补丁，新记录校验通过后才替换，并保留历史。
        
        
        
      
        

      
        
        
        内置适配
        
        
        使用启动器自带的专用适配器还原，不走通用记录。
        
        
        
      
        

      
        
        
        未记录 0
        
        
        这些插件安装时没有建立快照，无法得知改过哪些文件。组合切换已暂停；需先恢复干净的安装，再通过启动器安装并自动记录，不能把现状冒充原始文件。
        
        
        
      
        

      
        
        记录范围与限制
        
        安装和首次运行期间只操作这个插件，不进行其他文件编辑。启动器会检测其他插件、组合和程序版本是否变化，校验文件与双向还原数据后自动保存；有异常时保留记录并暂停。
        
        
          
        
          默认排除账号凭据文件、会话目录和 profile 插件依赖目录，不监控注册表、系统服务及其他磁盘路径。链接新增或类型互换会停止自动登记。发生共享文件冲突时停止覆盖，不强行合并。
          
        
          完整哈希校验可能较慢，文件副本按内容去重。后续运行或更新若产生记录外变化，会停止自动还原，不能据此宣称整台电脑恢复原样。
